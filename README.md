# Atelier de lectură – aplicații PWA

Șase aplicații interactive pentru lecțiile 9–14, optimizate pentru tablete și copii de 6–8 ani. Fiecare lecție are un link stabil în GitHub Pages și folosește un cod QR static. Codurile QR nu au termen de expirare; ele conțin direct adresa paginii. Linkurile funcționează cât timp repository-ul și GitHub Pages rămân publice.
